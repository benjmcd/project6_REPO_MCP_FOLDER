This freeze selects the first live SEC EDGAR source-artifact acquisition runtime for the SEC EDGAR text/table source family. The selected future runtime may acquire exactly one allowlisted complete-submission text filing artifact, identified by server-validated CIK/accession/form/filing-date fields, and may record a redacted append-only live source-artifact receipt that can feed the existing source-acquisition authority path.

The future runtime must derive any SEC Archives URL server-side from validated CIK and accession identity. Browser-supplied raw SEC URLs, local paths, commands, artifact bytes, or durable authority remain invalid inputs. The runtime must use a server-configured identifying User-Agent, moderate requests, and stay below the official SEC fair-access ceiling; CI proof must use a fake SEC client and must not make live network calls.

This freeze does not implement live SEC acquisition. It also does not admit parser expansion, XML/HTML/inline XBRL parsing, DatasetVersion materialization, Gate B mutation, new runtime storage roots, provider writes, connector dispatch, RAG/model runtime, auth/security expansion, full mockup activation, browser storage authority, or frontend durable authority.
