The selected product runtime must not fetch SEC content, reparse HTML/iXBRL, reconstruct raw fact values, expose raw URLs or local paths, resolve taxonomies, call SEC CompanyFacts, process standalone XML/XBRL, broaden parser/source scope, mutate existing Gate B or downstream proof state, start background processes, dispatch connectors, write provider objects, run RAG/model logic, activate full mockup behavior, or create browser-held durable authority.

## Runtime Requirements

1. Load and validate an existing statement-classification receipt by id plus expected receipt hash.
2. Revalidate the classification receipt against its fact authority, fact material bridge, parser, connector, source artifact, dataset version, and Gate B hashes.
3. Build a redacted product manifest with statement candidate summaries, role group inventories, table-anchor crosswalks, unknown diagnostics, authority provenance, and downstream readiness metadata.
4. Preserve classification order, statement-group order, source order, marker order, and table-anchor order.
5. Reconcile every retained fact into exactly one product group or unknown diagnostic with count/hash parity against the classification receipt.
6. Store only append-only product receipts and redacted status projections: counts, hashes, group summaries, unknown diagnostics, table-anchor summaries, redaction metadata, and authority hashes.
7. Fail closed on stale authority, missing classification/fact/bridge authority, inventory mismatch, count mismatch, Gate B mismatch, forbidden input fields, raw path/URL/value exposure, browser-owned content, or missing redaction manifest.
