This runtime turns a connector-acquired HTML/iXBRL complete-submission text artifact into a redacted parser receipt. It reads only the server-retained artifact already governed by the SEC connector and live source-artifact receipts, validates stale hash boundaries, records document inventory, primary-document binding, source-order text segment evidence, HTML table candidate hashes, inline XBRL marker hashes, diagnostics, and a redacted status projection.

This runtime does not fetch SEC data, accept browser-supplied URLs or uploads, create DatasetVersions, mutate Gate B, bridge to Layer 3 materials, create XBRL fact authority, extract financial semantics, write provider objects, dispatch connectors, run RAG/model logic, activate full mockups, or expose raw URLs, local paths, storage roots, retained artifact bytes, or unredacted source refs. The next governed slice should select the smallest material bridge for HTML/iXBRL parser receipts; XBRL fact authority remains a separate later selection.
