This runtime implements only the selected SEC EDGAR complete-submission text filing acquisition slice. It derives the SEC Archives URL from validated CIK/accession identity on the server, requires a server-configured identifying User-Agent before any network/fake-client fetch, records redacted append-only receipt authority plus a retained artifact under the existing Layer 3 storage root, and exposes a redacted status endpoint.

This does not parse SEC content, create DatasetVersion materialization, mutate Gate B, add rendered controls, expose raw SEC URLs or local paths, dispatch connectors, write provider objects, add RAG/model runtime, activate full mockups, or create frontend durable authority.
