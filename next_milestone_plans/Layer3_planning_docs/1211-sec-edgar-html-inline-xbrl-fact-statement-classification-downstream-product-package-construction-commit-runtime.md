This runtime implements the selected SEC HTML/iXBRL statement-candidate product package construction commit over existing package-review preview receipts. It creates an append-only construction receipt, writes redacted server-owned package payload artifacts for `canonical_internal`, `review_facing`, and `user_facing`, and returns hash-only payload/status projections for later package-review submit.

The runtime revalidates package-review preview authority and expected upstream hashes before writing payload artifacts. It does not submit package-review decisions, prepare handoff/export, deliver artifacts, fetch SEC content, reparse HTML/iXBRL, reconstruct raw fact values, resolve taxonomies, call SEC CompanyFacts, process standalone XML/XBRL, broaden parser/source scope, dispatch connectors, write provider objects, run RAG/model logic, activate full mockup behavior, or create browser-held durable authority.
