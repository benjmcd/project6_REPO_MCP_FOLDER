This runtime implements the selected fact-authority slice only. It reloads an existing parser receipt, re-reads the retained live source artifact through server-owned source-artifact authority, validates all parser/source hashes, extracts ordered inline XBRL fact elements from the retained primary document, and records a deterministic fact-authority receipt with redacted operator/status projections.

The runtime deliberately does not fetch from SEC, accept browser-submitted HTML, accept raw URLs or local paths, process standalone XML XBRL, call SEC Company Facts, resolve taxonomy networks, assign financial-statement semantics, mutate the existing text/table material bridge, mutate Gate B, mutate downstream proof/status, dispatch connectors, write provider objects, add RAG/model runtime, or activate full mockup behavior. The next governed step is a separate selection for carrying fact authority into Layer 3 material/evidence authority.
