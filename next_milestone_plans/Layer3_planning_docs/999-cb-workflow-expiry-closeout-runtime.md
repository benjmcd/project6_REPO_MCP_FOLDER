This runtime implements the lifecycle slice selected in `998-cb-workflow-lifecycle-selection.md`. The lifecycle endpoint revalidates the current server-owned workflow-run history row, binds the request to the current `history_hash`, `row_hash`, `operator_workflow_receipt_hash`, and `authority_basis_hash`, and writes a separate lifecycle receipt.

The source workflow-run receipt is not mutated. The operator can continue to inspect the original run through the returned status request. Idempotency is bound to `client_request_id` plus the lifecycle authority hash, and stale or missing authority fails closed.

Cancel, retry, resume, queue scheduling, broader default scope, provider object writes, connector dispatch, RAG/vector/model runtime, full mockup activation, browser storage authority, and frontend durable authority remain unselected.
