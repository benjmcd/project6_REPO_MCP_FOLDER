This runtime implements the selected SEC EDGAR live source-artifact material-authority bridge. It verifies the live source-artifact receipt and retained content hash, verifies the source-acquisition receipt and its hash payload, requires the same source-artifact receipt authority on both sides, requires a ready materialized DatasetVersion authority envelope, and then reuses the existing SEC EDGAR material-authority bridge to produce material-preview and Gate B compatibility.

The runtime does not fetch from SEC, parse retained filing bytes, create DatasetVersion rows, mutate Gate B, widen source classes, write provider objects, dispatch connectors, add RAG/model runtime, activate full mockups, or create frontend/browser durable authority.

## Coherence Check

- Does this make a live retained source artifact a direct material payload? Recommended answer: no. It remains evidence/provenance/inspection authority until bound through source-acquisition authority and an existing materialized DatasetVersion authority envelope.
- Why was source-acquisition compatibility extended? Recommended answer: live source-artifact receipts and materialized provenance need an exact shared source-artifact receipt id/hash/ref binding; the extension uses explicit receipt fields from materialized provenance and preserves legacy computed receipt behavior when those fields are absent.
- Does this endpoint replace the existing material-authority bridge? Recommended answer: no. It composes and reuses `sec_edgar_text_table_authority_envelope_to_layer3_material_authority_v1`.
- What comes next? Recommended answer: sync this runtime to current main, then select the rendered/status or downstream proof slice that proves live source-artifact material authority through operator-visible Layer 3 downstream inspection.
