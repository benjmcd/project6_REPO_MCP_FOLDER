This runtime implements the selected SEC HTML/iXBRL statement-candidate product package-review submit slice over existing package-construction receipts. It records an append-only review-submit receipt, enforces bounded decisions and non-approved decision notes, rejects duplicate conflicting decisions, and returns redacted decision/status authority for later handoff/export selection.

The runtime revalidates package-construction authority and expected upstream hashes before writing the review-submit receipt. It does not mutate package payloads, prepare handoff/export, deliver artifacts, fetch SEC content, reparse HTML/iXBRL, reconstruct raw fact values, expose decision notes, resolve taxonomies, call SEC CompanyFacts, process standalone XML/XBRL, broaden parser/source scope, dispatch connectors, write provider objects, run RAG/model logic, activate full mockup behavior, or create browser-held durable authority.
