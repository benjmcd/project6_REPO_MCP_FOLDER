This runtime implements the selected downstream product evidence slice over existing SEC HTML/iXBRL statement-classification receipts. It turns redacted candidate statement groups, table anchors, unknown diagnostics, authority provenance, and downstream readiness metadata into an append-only product receipt and status projection.

The runtime does not fetch SEC content, reparse HTML/iXBRL, reconstruct raw fact values, resolve taxonomies, call SEC CompanyFacts, process standalone XML/XBRL, mutate Gate B or downstream proof state, dispatch connectors, write provider objects, run RAG/model logic, activate full mockup behavior, or create frontend durable authority. It also does not claim final audited financial statement semantics.

## Coherence Check

- Does this create final SEC financial statements? Recommended answer: no. It creates redacted statement-candidate product evidence for operator inspection and later package/review flow.
- Are unknown facts dropped? Recommended answer: no. Unknown facts remain explicit diagnostics and must count/hash reconcile with the source classification receipt.
- Does this add a new SEC network, parser, taxonomy, or CompanyFacts runtime? Recommended answer: no. It only consumes already-issued statement-classification, fact-authority, and fact-material bridge authority.
- What comes next? Recommended answer: sync this runtime to current main after merge, then select the next downstream product package/review or rendered operator inspection slice from current-main evidence.
