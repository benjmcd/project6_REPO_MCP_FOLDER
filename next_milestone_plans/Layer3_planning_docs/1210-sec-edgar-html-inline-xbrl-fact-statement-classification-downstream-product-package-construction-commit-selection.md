This freeze selects the next governed SEC HTML/iXBRL package lifecycle slice. The future runtime should commit an existing package-review preview receipt into durable, server-owned package construction authority: one construction receipt, redacted package payload artifacts for `canonical_internal`, `review_facing`, and `user_facing`, and hash-only status suitable for later package-review submit.

The selected runtime must not submit package review decisions, prepare handoff/export, deliver artifacts, fetch SEC content, reparse HTML/iXBRL, reconstruct raw fact values, resolve taxonomies, call SEC CompanyFacts, process standalone XML/XBRL, broaden parser/source scope, dispatch connectors, write provider objects, run RAG/model logic, activate full mockup behavior, or create browser-held durable authority.

## Runtime Requirements

1. Load and validate an existing package-review preview receipt by id plus expected receipt hash.
2. Revalidate the preview receipt against downstream product, statement-classification, fact-authority, fact-material bridge, candidate-package manifest, review-readiness, package-order, product-order, redaction, and downstream-readiness hashes.
3. Commit redacted server-owned package payload artifacts for `canonical_internal`, `review_facing`, and `user_facing` without accepting caller-supplied payloads, paths, URLs, HTML, fact values, or bytes.
4. Preserve package kind order, product group order, table-anchor order, unknown diagnostic order, and payload manifest order.
5. Reference every package-review preview candidate, statement-candidate group, unknown diagnostic, and table-anchor crosswalk by hash so package construction does not discard product evidence.
6. Store only append-only construction receipts, redacted package payload artifacts, and redacted status projections: package counts, payload hashes, review readiness, redaction metadata, and authority hashes.
7. Fail closed on stale authority, missing preview/product/classification/fact/bridge authority, manifest mismatch, order mismatch, redaction mismatch, forbidden input fields, raw path/URL/value exposure, browser-owned content, payload writes outside server-owned storage, or review-submit/handoff/delivery mutation attempts.
