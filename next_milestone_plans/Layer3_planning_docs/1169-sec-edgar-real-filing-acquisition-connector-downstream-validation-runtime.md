This runtime records the first downstream-validation receipt for connector-acquired SEC examples. It requires a redacted SEC EDGAR real-filing connector receipt, one supported connector example, the matching live source-artifact receipt, source-acquisition authority, live material bridge, downstream proof, and available operator-status authority. It revalidates the existing operator-status request server-side and records only an append-only redacted validation receipt.

This runtime does not fetch SEC data, parse retained filing bytes, create DatasetVersions, mutate Gate B, create package/delivery artifacts, write provider objects, dispatch generic connectors, run RAG/model logic, activate full mockups, or make Candidate B the general SEC parser. HTML/iXBRL remains classified but not parsed until a separate source-family parser slice is selected.
