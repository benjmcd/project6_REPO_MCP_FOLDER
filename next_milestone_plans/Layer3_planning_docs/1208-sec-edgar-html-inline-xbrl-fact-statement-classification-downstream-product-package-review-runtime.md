This runtime implements the selected SEC HTML/iXBRL statement-candidate product package-review preview over existing downstream product receipts. It creates an append-only package-review preview receipt with redacted candidate package manifests for `canonical_internal`, `review_facing`, and `user_facing` package roles, plus review-readiness, package-order, redaction, and authority hashes.

The runtime revalidates the downstream product receipt and expected upstream hashes before producing preview authority. It does not create package rows, submit package-review decisions, prepare handoff/export, deliver artifacts, fetch SEC content, reparse HTML/iXBRL, reconstruct raw fact values, resolve taxonomies, call SEC CompanyFacts, process standalone XML/XBRL, broaden parser/source scope, dispatch connectors, write provider objects, run RAG/model logic, activate full mockup behavior, or create browser-held durable authority.
